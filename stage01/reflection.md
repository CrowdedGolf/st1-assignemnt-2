What did you build before using AI?
A basic python program to store appointment details designed to fulfill the clients’ requirements.
 
What did AI help you understand?
The AI did not help me understand anything new as I already understood almost everything about the program as this is quite basic Python. I can see it being useful to help break down and explain some more complex functions though.

Did AI make assumptions?
The AI assumed that I only wanted to make an entry system that instantly displayed the entered data with no function to retrieve said data since I specified simplicity. The human made version did have a function to show the current appointments which is very useful as it allows the medical practices to look up when appointments are so there are no double bookings.
 
How did you verify the AI output?
I verified that the AI’s output functioned correctly by using multiple test cases to make sure that the expected outputs are produced when given specific inputs.
 
What engineering work remained for you?
The engineering work that remained for me was, testing if the program worked as expected, identifying requirements and if the system met those requirements, and marking areas for improvement and or changes.
