US-01: As a Practitioner, I want to be able to create appointments, so that I can schedule appointments with patients.
US-02: As a Patient, I want to be able to view practitioner availability, so that I can book an appointment with a practitioner that fits when we are available.
US-03: As a member of management, I want a simple centralised system, so that I can easily view and act on information.
US-04: As a Practitioner, I want to easily locate patient records, so that I can do my job more effectively.
US-05: As a Practitioner, I want a reliable appointment history, so that I can keep track of repeat patients.
US-06: As a Patient, I want an easy digital cancelation system, so that I can easily reschedule and reduce pressure on the Practitioners.
